# Personal Finance Dashboard

A Python-based finance analysis project focused on processing, cleaning, and analyzing personal financial data in a structured and privacy-friendly way.

The goal of this project was to strengthen my skills in **Python programming**, **data analysis**, and **software structuring** by building a practical real-world application for financial insights and transaction analysis.

---

## Features

- Import and preprocessing of bank CSV files
- Transaction analysis and financial summaries
- Income vs. expense analysis
- Category-based spending overview
- Basic financial statistics
- 80/20 Pareto analysis
- Clean and scalable project structure
- Protection of sensitive financial data using `.gitignore`

Additionally implemented:
- Automated transaction categorization
- Configurable rule-based categorization system using JSON

---

## Technologies Used

- **Python**
- **Pandas** – data analysis & transformation
- **JSON** – configurable categorization rules
- **Git & GitHub** – version control and documentation

No personal banking data is included in this repository.

Sensitive files are excluded using `.gitignore`, and the project can also work with publicly available datasets such as downloadable Kaggle finance datasets.
