# Personal Finance Dashboard (Work in Progress)

Mein erstes größeres Python-Projekt, mit dem ich meine Skills in **Datenanalyse** und **Python-Programmierung** ausbaue.  
Ziel ist es, Finanzdaten zu analysieren, zu visualisieren und daraus Insights abzuleiten – komplett automatisiert und datenschutzfreundlich.

---

## Ziele des Projekts

- Meine Python-Kenntnisse kontinuierlich verbessern  
- Praktische Erfahrung mit Data Cleaning, Pandas, Automatisierung und Streamlit sammeln  
- Ein echtes, nützliches Tool für meine eigenen Finanzen entwickeln  
- Ein Projekt aufbauen, das ich langfristig erweitern kann  
- Ein öffentlich einsehbares Portfolio-Projekt schaffen

---

## Bisher umgesetzt

- Grundstruktur für das Projekt erstellt (`src/` Ordner)
- Einlesen und Vorverarbeiten von Bank-CSV-Dateien
- Implementierung von Basis-Analysen:
  - Summe pro Kategorie
  - Einnahmen vs. Ausgaben
  - Grundstatistiken
- Saubere Ordnerstruktur & Schutz sensibler Daten mittels `.gitignore`
- Repository professionell neu strukturiert
- 80/20 Pareto-Analyse

Diese Funktionen habe ich geschrieben, sind aber nicht im Gebrauch:
- Erste automatisierte Kategorisierung von Transaktionen
- Erstellung eines konfigurierbaren Regelwerks (`category_rules.json`)

## Datenschutz

Persönliche Bankdaten werden **nicht** veröffentlicht.  
Dazu verwende ich eine `.gitignore`, die sicherstellt, dass CSV-Dateien und sensible Informationen lokal bleiben. Außerdem ist der verwendete Datensatz online auf Kaggle frei downloadbar. Hier geht es mir nur ums Prizip.
